Resource and project in Microsoft Foundry

Every Foundry setup starts with two things: a Foundry resource, and a project inside it. Here's what lives where, why the first project is special, and how cleanup works.

Checked 31 Oct 2026

What lives where

The resource holds the things every project shares: model deployments, connections to other services, and network and security settings. A project is where you actually build: agents, files, evaluations, datasets and indexes. The first project on a resource is its default project. When we created our resource in the Azure portal, the form asked for a default project name and created both in one deployment.

Who can work in a project

Creating a resource and building inside a project need different permissions. That's the next step: roles and identities.

Two cleanup rules

Deleting a project and deleting the resource behave differently. Know which one you're doing.

Rule 1 · Project

A deleted project can't be recovered

Microsoft's page is plain about it: a deleted project is gone, along with the work inside it. There's no recovery window like the resource has.

Microsoft Learn, Create a project · checked 31 Oct 2026
Rule 2 · Resource

A deleted resource holds its name for 48 hours

Microsoft Learn describes a 48-hour window to recover or purge a deleted resource under "Manage deleted resources". Until it's purged, the name can't be reused. If you deleted the resource group too, you recreate it before recovering. The portal's delete dialog we saw warns the resource "will be permanently deleted", so don't plan on getting it back.

Microsoft Learn, Recover or purge deleted resources · observed dialog 31 Oct 2026

Following an older tutorial?

Before New Foundry, projects were built on a Foundry hub, now called a hub-based project. Those still exist and appear only in the classic portal, behind the "New Foundry" switch. Microsoft says its new investments are focused on Foundry projects in the new portal, like the ones on this page. If a tutorial's screens don't match yours, check which project type it uses.
