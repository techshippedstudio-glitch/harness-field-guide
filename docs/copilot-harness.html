Harness engineering · Microsoft Foundry

The Copilot harness, drawn out

Microsoft's Copilot harness runs the agent loop and the sandbox for you. You bring the instructions, skills, tools and a model. This page shows what sits on each side of that line.

Checked 31 Oct 2026Public preview

What you bring, what Microsoft runs

The harness is chosen when you create a prompt agent. From then on, Foundry runs the loop that plans each step, calls tools, runs code in a sandbox and hands bounded work to subagents. Your job is the material the loop works with.

Which kind of agent do you need?

Foundry offers three levels. Each one gives you more control and more to own. Microsoft's advice is to pick the level that matches what you need, rather than owning infrastructure you don't.

Preview facts, with dates

The harness is in public preview, so these change. Each card says when we last checked it.

Preview limit

Chosen at creation

You pick the harness when you create the agent. Existing agents don't change, and switching an agent to the harness later isn't supported yet.

Billing

Runtime free until 1 Dec 2026

From 1 Dec 2026 the sandbox is billed at $0.0994 per vCPU-hour and $0.0118 per GiB-hour. Model calls and separately billed tools are charged at their own rates today. Prices may vary by region and agreement.
