Check these claims about the Microsoft Copilot harness in Microsoft Foundry.

1. You choose the Copilot harness when you create a prompt agent; during the initial public preview you can't switch an existing agent to it.
   Source: https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/use-tools-skills-copilot-harness

2. A Copilot harness agent can reference up to 50 top-level skills, and each reference resolves to an immutable version.
   Source: https://learn.microsoft.com/en-us/azure/foundry/agents/concepts/limits-quotas-regions

3. The harness's built-in tools are file read, file write, shell, web and subagents, and they're enabled by default.
   Source: https://learn.microsoft.com/en-us/azure/foundry/agents/concepts/limits-quotas-regions

4. Foundry Memory stores and memory tools are available to agents that use the Copilot harness.
   Source: https://learn.microsoft.com/en-us/azure/foundry/agents/concepts/limits-quotas-regions
