# Code and examples

One folder per episode that has code, each with its own README (prerequisites, setup steps and the exact
tool versions used). Each episode's state is tagged in git, for example `ep02`.

| Episode | Folder | Notes |
|---|---|---|
| 1 | none | Portal only |
| 2 | coming | A Copilot harness agent defined in code and deployed with the Azure Developer CLI |

Samples never contain keys or account details; they read settings from your own environment.
