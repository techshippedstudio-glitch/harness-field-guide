# Code and examples

One folder per episode that has code, each with its own README (prerequisites, setup steps and the exact
tool versions used). Each episode's state is tagged in git, for example `foundry-ep02` (release) and `foundry-ep02-recorded` (as shown in the video).

| Episode | Folder | Notes |
|---|---|---|
| 1 | none | Portal only |
| 2 | [`ep02-first-useful-agent`](ep02-first-useful-agent/) | A fact-checking prompt agent on the Copilot harness, defined and run with the Azure AI Projects SDK for Python |

Samples never contain keys or account details; they read settings from your own environment.
